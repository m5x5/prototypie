# Changelog

## 0.1.0 (unreleased)

First public version: the native macOS app and the web app in one repository.

- Native app: infinite canvas of design cards, explorations, fullscreen with live view, review dock, polls, compare,
  agent tasks panel with copyable commands, annotate mode with its own notes service, `prototypie` command and agent skill, project list with optional pod and folder
  sources, collapsible sidebar, dark glass header.
- Web app: the original Next.js implementation.
